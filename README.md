# Vue3 Firebase App2 (vue3-firebase-app2)

Vue3 Quasar Firebase TypeScript App 커뮤니티 사이트

## 프로젝트 실행

```bash

npm install
npm run dev
```

- auto Rename Tag
- auto close tag
- prettier
- vue vscode snippets
- rainbow brackets
- indent-rainbow
